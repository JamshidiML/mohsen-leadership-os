# Mohsen Leadership OS

یک سیستم عامل سه‌ساله برای تبدیل توان فنی و بلندپروازی محسن به ظرفیت قابل مشاهده در **خودرهبری، ارتباطات، شبکه‌سازی، مذاکره، تیم‌سازی، مدیریت استارتاپ و حضور سالم در خانواده**.

- **شروع رسمی:** یکشنبه 2026-08-16
- **اولین هفته اجرایی:** دوشنبه 2026-08-17 تا یکشنبه 2026-08-23
- **پایان چرخه اول:** 2029-08-15
- **مالک تصمیم‌ها:** Mohsen
- **وضعیت پیشنهادی مخزن:** Private
- **ریتم:** روزانه سبک، هفتگی اجرایی، ماهانه تحلیلی، فصلی راهبردی، سالانه بازطراحی

## تعریف موفقیت

هدف، تقلید از شخصیت استیو جابز یا ایلان ماسک نیست. هدف، ساختن قابلیت‌هایی در سطح مدیران مؤثر جهانی است، بدون کپی‌کردن رفتارهای آسیب‌زا:

1. وضوح فکری و تصمیم‌گیری زیر فشار
2. سخن‌گفتن کوتاه، قانع‌کننده و متناسب با مخاطب
3. ایجاد و نگهداری شبکه‌ای معتبر در آلمان و اکوسیستم بین‌المللی
4. مذاکره مبتنی بر منافع، قدرت، گزینه‌ها و اخلاق
5. تشکیل تیم و ایجاد امنیت روانی، مسئولیت‌پذیری و سرعت اجرا
6. اداره یک استارتاپ با سیستم، نه با قهرمان‌بازی و فرسودگی
7. رابطه گرم، محترمانه و قابل ترمیم با همسر و دختر؛ بدون کنترل یا امتیازدهی به آن‌ها

## قانون طلایی

این مخزن فقط رفتارهای خود محسن را مدیریت و ارزیابی می‌کند. همسر، دختر، همکار یا تیم «موضوع آزمایش» نیستند و بدون رضایت وارد ارزیابی یا ثبت داده نمی‌شوند.

## شروع سریع

1. [راهنمای شروع رسمی](START_HERE.md) را بخوانید و فقط بلوک‌های زمانی لازم را در تقویم قرار دهید.
2. یک محل شخصی و خارج از Git برای Evidence انتخاب کنید؛ نام افراد، اطلاعات تماس، پیام‌ها و جزئیات محرمانه را در این مخزن ثبت نکنید.
3. در یکشنبه 2026-08-16، Kickoff کوتاه را انجام دهید.
4. از دوشنبه 2026-08-17، [برنامه هفته اول](plans/week-001.md) را اجرا کنید.

این مخزن در وضعیت فعلی یک سیستم اجرایی مبتنی بر Markdown است و برای شروع به نصب Python، Conda یا ابزار دیگری نیاز ندارد.

## GitHub و حریم خصوصی

- مخزن را **Private** نگه دارید.
- GitHub فقط برای نسخه‌بندی ساختار، برنامه‌ها و Templateهای بدون داده شخصی است.
- Evidence واقعی در محل شخصی خارج از Git می‌ماند؛ در Git فقط می‌توان Count و آموخته کاملاً ناشناس را ثبت کرد.
- Branch، Issue و Pull Request نباید شامل نام مخاطبان، متن پیام، تعارض، داده شرکت یا اطلاعات پزشکی باشد.
